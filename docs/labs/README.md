# Labs

**Status: Planned, not yet implemented as standalone content.**

The engineering-academy curriculum (`docs/ROADMAP.md`) describes 24 hands-on modules, each
with a "build / break exercise" and required evidence (an incident note, a packet trace, a
load-test report, and so on). None of those lab write-ups exist as documentation yet — the
roadmap table is the plan, not a completed log.

Two related templates already exist and are linked from **Operations** rather than duplicated
here: `docs/incidents/README.md` (incident lab log template) and `docs/cost-reports/README.md`
(cost experiment report template). As individual labs are actually run, their write-ups belong
here, cross-referencing the roadmap module they correspond to — not fabricated in advance.
