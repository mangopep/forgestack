# security-review
Inspect changed or scoped files. Check OWASP API issues, authz, secrets, logging PII, SSRF/injection, dependency risks, GitHub workflow tokens, IaC permissions and storage exposure. Run locally available safe scanners, report commands actually used and coverage. Do not exploit external systems or modify secrets.
